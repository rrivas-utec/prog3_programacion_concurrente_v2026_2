## Indicaciones Específicas
El tiempo límite para la evaluación es 120 minutos.

Cada pregunta deberá ser respondida en un archivo cabecera dentro de `include/` y, cuando corresponda, en un archivo fuente dentro de `src/`:

 - `include/clasificacion_numeros.h` `src/clasificacion_numeros.cpp`
 - `include/suma_rangos.h` `src/suma_rangos.cpp`
 - `include/suma_archivos.h` `src/suma_archivos.cpp`
 - `include/frecuencia_numeros.h` `src/frecuencia_numeros.cpp`
 - `include/cliente_bancario.h` `src/cliente_bancario.cpp`
 - `include/logger.h` `src/logger.cpp`
 - `include/productor_consumidor.h` `src/productor_consumidor.cpp`
 - `include/lectura_ciclica.h` `src/lectura_ciclica.cpp`
 - `include/sala.h` `src/sala.cpp`  

Deberás subir estos archivos directamente a www.gradescope.com o se puede crear un .zip que contenga todos ellos y subirlo.

## Public tests in your IDE

Open the project with CMake in CLion or VS Code. Run only the target for the
question you are implementing, for example `public_test_question_1`. The
`public_tests_all` target is intended for the final review of all questions.
